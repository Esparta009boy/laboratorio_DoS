# 🧪 LABORATÓRIO DE ATAQUE DoS (SLOWLORIS)

![Capa do Projeto](https://www.shutterstock.com/image-photo/hooded-hacker-online-security-concept-260nw-2415998581.jpg)

## 🛡️ Guia Interativo de Simulação de Ataque DoS

Este projeto apresenta um laboratório prático em **formato HTML** para simulação de ataque DoS utilizando a ferramenta **Slowloris**. Ideal para profissionais de segurança cibernética, estudantes e analistas SOC que desejam entender o funcionamento, impacto e mitigação de ataques de exaustão de conexões.
